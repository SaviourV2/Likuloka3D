# Furniture models

These GLB files are from the Furniture Kit (2.0) by Kenney, https://kenney.nl/assets/furniture-kit, released under Creative Commons Zero (CC0). `LICENSE.txt` is the licence file that ships with the kit. Only the models the planner uses are kept here.

`../models.js` is generated from this folder by `node tools/pack-models.js`. It holds the same files as base64 text, so the page can read them without a web server.
